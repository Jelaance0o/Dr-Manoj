# Dr. Manoj Bandwar Homeopathy

A modern, responsive healthcare website for **Dr. Manoj Bandwar Homeopathy**, built with React and Vite.

The website provides information about the clinic, treatments, doctor, services, and allows visitors to explore the clinic and booking-related information through a clean and interactive interface.

## ✨ Features

- 🏥 Modern homeopathy clinic website
- 👨‍⚕️ Doctor information and profile
- 💊 Treatments and services section
- 📋 Clinic information
- 📅 Booking form
- 📍 Location and map section
- ❓ Frequently Asked Questions
- ⭐ Testimonials section
- 📞 Contact information
- 📱 Responsive design
- 🎨 Modern UI and animations
- 🔢 Animated statistics and counters
- 🖱️ Smooth scrolling
- ✨ Interactive UI elements
- 📜 Treatment information sections
